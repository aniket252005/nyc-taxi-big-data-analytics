# 📄 Project Report — Big-Data Analytics on NYC Taxi Trips

## 1. Executive Summary

This project demonstrates end-to-end Big Data analytics on the NYC Yellow
Taxi Trip Record dataset using **PySpark**, **Spark SQL**, and **Databricks**.
The pipeline ingests raw Parquet data, performs comprehensive data quality
checks, engineers analytical features, runs 12+ Spark SQL queries, and
produces Gold-layer aggregated tables consumable by **Power BI**.

The project follows the industry-standard **Bronze → Silver → Gold**
(Medallion) architecture and showcases practical Spark optimization
techniques with benchmarked comparisons.

---

## 2. Business Problem

New York City's taxi industry generates millions of trip records monthly.
Stakeholders — including fleet operators, city planners, and regulatory
bodies — need actionable insights into:

- **When** demand peaks (hour, day, weekday vs weekend)
- **Where** demand concentrates (pickup/drop-off zones)
- **How much** revenue each zone and time period generates
- **Customer behavior** patterns (tipping, payment methods, trip lengths)

These insights enable data-driven decisions for fleet deployment, surge
pricing, infrastructure planning, and service optimization.

## 3. Methodology

### 3.1 Data Ingestion (Bronze Layer)
- Source: NYC TLC official Parquet files
- Downloaded programmatically via `src/ingestion.py`
- Schema validated against 19 expected columns

### 3.2 Data Quality & Cleaning (Silver Layer)
- **Null detection** across all key columns
- **Duplicate detection** using `DataFrame.distinct()`
- **Row-level validation** with configurable thresholds for:
  - Passenger count (1–9)
  - Trip distance (0.1–200 mi)
  - Trip duration (1 min – 5 hrs)
  - Fare amount ($2.50–$500)
  - Tip amount ($0–$200)
  - Timestamp range (2019–2026)
  - Non-negative total amounts

All quality metrics are **computed from the actual dataset** — no fabricated
numbers.

### 3.3 Feature Engineering
Derived 12+ features using native PySpark functions:

| Feature              | Source                         | Spark Function             |
|----------------------|--------------------------------|----------------------------|
| pickup_hour          | tpep_pickup_datetime           | F.hour()                   |
| pickup_day_of_week   | tpep_pickup_datetime           | F.dayofweek()              |
| trip_duration_minutes| pickup – dropoff timestamps    | F.unix_timestamp() diff    |
| average_speed        | distance / duration            | Conditional division       |
| fare_per_mile        | fare / distance                | Conditional division       |
| tip_percentage       | tip / fare × 100               | Conditional division       |
| is_weekend           | day_of_week ∈ {1, 7}           | F.when().isin()            |
| is_peak_hour         | hour ∈ {7–9, 16–19}            | F.when().between()         |
| day_type             | weekend / weekday label        | F.when()                   |

### 3.4 Spark SQL Analysis
12 analytical queries demonstrating:
- GROUP BY, HAVING, ORDER BY
- Common Table Expressions (CTE)
- CASE WHEN
- Window functions (RANK, DENSE_RANK, SUM OVER, AVG OVER)
- Date/time functions
- JOIN and CROSS JOIN

### 3.5 Performance Optimization
6 optimization techniques benchmarked:
1. Column selection (projection pushdown)
2. Predicate / filter pushdown
3. Broadcast joins
4. Repartition vs coalesce
5. Caching for repeated queries
6. Parquet partitioning

### 3.6 Gold Layer
11 aggregated tables saved as Delta (Databricks) or Parquet (local):
- Hourly / daily demand
- Peak vs off-peak
- Weekend vs weekday
- Top pickup/drop-off zones
- Revenue by hour/zone
- Payment distribution
- Distance distribution
- Zone revenue ranking

## 5. Recommendations

Based on the analytical results:

1. **Optimize fleet deployment** during identified peak hours to reduce
   passenger wait times and maximize utilization.
2. **Incentivize off-peak rides** with promotional fares to smooth demand
   and increase driver utilization during low-demand periods.
3. **Focus marketing** on high-revenue zones to maximize revenue per trip.
4. **Promote credit-card payments** — credit card trips show higher tip
   percentages, increasing driver earnings.
5. **Monitor short-distance trips** — a high proportion of sub-1-mile trips
   may indicate opportunities for micro-mobility alternatives.
